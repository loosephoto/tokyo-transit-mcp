# コーディング規約

## MCP stdio プロトコル保護
- `stdout` は JSON-RPC 専用。**`console.log` で stdout に書き込まない**。`src/config.mjs` が `console.log` を stderr へリダイレクト済み。
- サーバーは**ホットリロードなし**。`src/` 変更後は MCP サーバー再起動で反映。

## モジュール依存方向（一方向）
```
handlers → advice / data / lib → config
```
逆方向（data や lib が handlers を import する等）にしない。`config.mjs` は副作用（console.log 保護）を持つため `index.mjs` から最初に import する。

## 安全応答ロジック（荒天）
- 台風・浸水・降雪・凍結時は**自転車案内を自動非表示**（`isDisasterRisk`）。必要に応じて避難所リンク表示。
- 津波・災害系 `-test` でも自転車案内を抑止（実天気の特別警報と同様）。
- 水上・地上の災害案内は交通モード別に分離。津波時は水面・港湾部から離れ高台・津波対応避難場所への案内を重視。
- 避難候補を確定情報と誤認させず、**自治体の公式避難情報を優先する**表記を維持。

## 多言語（i18n）
- 入力言語（日/英/中）を自動判定し、応答全体をローカライズ。
- ユーザーが英語（中国語）質問なら `language: "en"`（`"zh"`）を**明示指定**。駅名が日本語のままの英語質問では自動判定が ja に化ける。
- AIインテリジェントアドバイスは原文形式（🤖ヘッダー+本文）を維持し、独自見出しに書き換えない。

## 曖昧性の扱い
- 駅名・バス停名が曖昧（複数候補）な場合は**サイレント推測を嫌い、検索中断＋候補提示（disambiguation）**。完全一致→前方一致→包含の順で一意のみ解決。
- 特急・新幹線は経路グラフ非対応（駅案内のみ）。
- `search_fare` の `fare: null` は JR・私鉄等 ODPT運賃対象外の**正常動作**（対応7事業者で検証してから判断）。

## 公的機関案内
- `gov_facility_search_support` はラベル文字だけでなく**実リンク（markdown）を必ず表示**。
